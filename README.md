# Convex components

Reusable Convex components extracted from production applications after their contracts have been proven against real traffic.

## Packages

- [`@shpitdev/convex-openrouter-observability`](packages/openrouter-observability): an authenticated OpenRouter Broadcast OTLP trace drain with host-owned blob storage, typed projections, bounded correlation queries, deduplication, and retention.

The repository is a pnpm workspace. Run `pnpm check` for formatting, lint, type checks, tests, and packed-artifact verification.

See [PUBLISHING.md](PUBLISHING.md) for the public npm release process.
